---
title: Knowledge Base
description: Configure Milvus and an OpenAI-compatible embedding model API
---

The knowledge base writes tool documentation and parameter descriptions to Milvus for AI-assisted tool discovery and workflow design. The current configuration uses one flat `[knowledge_base]` section:

```toml
[knowledge_base]
milvus_url = "http://localhost:19530"
embedding_model = "Qwen/Qwen3-Embedding-4B"
base_url = "https://api.siliconflow.cn/v1/"
api_key = ""
```

| Key | Default | Description |
| --- | --- | --- |
| `milvus_url` | `http://localhost:19530` | Milvus address; automatic initialisation updates it when the default port is occupied. |
| `embedding_model` | `Qwen/Qwen3-Embedding-4B` | Model name sent to the embedding API. |
| `base_url` | SiliconFlow `/v1/` | OpenAI-compatible API root. |
| `api_key` | Empty | Embedding service credential. |

`auto-init` prompts for the embedding model, base URL, and API key. Preset-data initialisation needs both the embedding API and Milvus to be available so it can build vector indexes.

<Callout type="warn">
  `use_local_model`, `[knowledge_base.remote]`, and `[knowledge_base.local]` from older documentation are no longer valid settings. Unknown fields are ignored.
</Callout>

A self-hosted model uses the same OpenAI-compatible API path; no local-mode switch is required. See [Embedding Model](/docs/configuration/knowledge-base/embedding-model).
