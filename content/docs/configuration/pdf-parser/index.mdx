---
title: PDF Parser
description: Configure the Open MinerU service used by AI agents to read scientific papers
---

The PDF parser extracts Markdown and images from papers before writing the documents to the knowledge base. The currently implemented runtime engine is `open_mineru`:

```toml
[pdf_parser]
engine = "open_mineru"
batch_size = 5

[pdf_parser.open_mineru]
api_url = "http://localhost:8000"
timeout = 600
```

| Key | Default | Description |
| --- | --- | --- |
| `engine` | `local` | Parser engine name; set it to `open_mineru` when PDF parsing is needed. |
| `batch_size` | `5` | PDF parsing batch configuration. |
| `open_mineru.api_url` | `http://localhost:8000` | Open MinerU API root. |
| `open_mineru.timeout` | `600` | Request timeout in seconds. |

<Callout type="warn">
  The configuration type still accepts the names `mineru`, `doc2x`, `grobid`, and `local`, but the current PDF parser dispatcher only implements `open_mineru`. Selecting another value causes an unsupported-engine error when parsing.
</Callout>
