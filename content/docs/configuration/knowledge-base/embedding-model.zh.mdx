---
title: 嵌入模型
description: 为知识库配置远程 API 或本地嵌入推理
---

嵌入模型会将工具文档和参数说明转换为向量，再存储到 Milvus 中。BioFlowAI 支持两种模式：

- **远程 API**：调用兼容 OpenAI 的嵌入 API。这是默认模式，不需要本地 GPU。
- **本地模型**：在您自己的服务器上运行嵌入模型。适用于私有网络、离线部署或高吞吐索引场景。

## 远程 API 模式

调用兼容 OpenAI 的嵌入 API 对文本进行向量化。

### config.toml

```toml
[knowledge_base]
use_local_model = false

[knowledge_base.remote]
model    = "Qwen/Qwen3-Embedding-4B"
base_url = "https://api.siliconflow.cn/v1/"
api_key  = ""
```

| Key | 说明 |
| --- | --- |
| `model` | API 接受的嵌入模型名称。 |
| `base_url` | API 基础 URL。默认使用 [SiliconFlow](https://siliconflow.cn)。 |
| `api_key` | 所选提供商的 API key。 |

如需使用其他提供商，请同时更新 `base_url` 和 `model`。任何暴露兼容 OpenAI 的 `/v1/embeddings` 端点的服务均可使用。

**SiliconFlow**（默认）：请在 [siliconflow.cn](https://siliconflow.cn) 注册以获取 API key。

## 本地模型模式

在本地运行嵌入模型。文本不会发送到外部 API。

### config.toml

```toml
[knowledge_base]
use_local_model = true

[knowledge_base.local]
model          = "Qwen/Qwen3-Embedding-4B"
use_modelscope = false
device         = "cuda:0"
```

| Key | 说明 |
| --- | --- |
| `model` | Hugging Face 模型 ID（当 `use_modelscope = true` 时为 ModelScope ID）。 |
| `device` | PyTorch 设备字符串：`cuda:0`、`cuda:1`、`cpu` 等。 |
| `use_modelscope` | 从 [ModelScope](https://modelscope.cn) 而非 Hugging Face 下载模型。中国大陆环境推荐启用。 |

### 使用 vLLM 部署

使用 vLLM 运行兼容 OpenAI 的嵌入服务器：

```bash
CUDA_VISIBLE_DEVICES=0 vllm serve Qwen/Qwen3-Embedding-4B \
    --served-model-name qwen3-embedding-4b \
    --host 0.0.0.0 \
    --port 5000 \
    --gpu-memory-utilization 0.9 \
    --max-model-len 20000 \
    --trust-remote-code
```

然后通过远程 API 模式将 BioFlowAI 指向本地服务器：

```toml
[knowledge_base]
use_local_model = false

[knowledge_base.remote]
model    = "qwen3-embedding-4b"
base_url = "http://localhost:5000/v1/"
api_key  = "EMPTY"
```

这样可以让 BioFlowAI 继续访问兼容 OpenAI 的端点，同时模型运行在您自己的 GPU 服务器上。
