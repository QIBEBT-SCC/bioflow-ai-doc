---
title: 嵌入模型
description: 配置远程或自托管的 OpenAI-compatible 嵌入 API
---

BioFlowAI 通过 OpenAI-compatible `/embeddings` API 生成向量。托管 API 和自托管服务使用相同配置：

```toml
[knowledge_base]
embedding_model = "Qwen/Qwen3-Embedding-4B"
base_url = "https://api.siliconflow.cn/v1/"
api_key = "YOUR_API_KEY"
```

| Key | 说明 |
| --- | --- |
| `embedding_model` | API 接受的模型名称。 |
| `base_url` | OpenAI-compatible API 根地址，通常以 `/v1/` 结尾。 |
| `api_key` | Provider API key；不鉴权的本地服务可使用空值或服务要求的占位值。 |

## 自托管示例

例如，使用 vLLM 提供嵌入端点：

```bash
CUDA_VISIBLE_DEVICES=0 vllm serve Qwen/Qwen3-Embedding-4B \
  --served-model-name qwen3-embedding-4b \
  --host 0.0.0.0 \
  --port 5000 \
  --task embed \
  --trust-remote-code
```

然后修改 BioFlowAI：

```toml
[knowledge_base]
embedding_model = "qwen3-embedding-4b"
base_url = "http://127.0.0.1:5000/v1/"
api_key = "EMPTY"
```

修改嵌入模型后，现有 Milvus 向量与新模型不兼容。请重建索引：

```bash
uv run bioflow-ai init rebuild-index
```
