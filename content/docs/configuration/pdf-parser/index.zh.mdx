---
title: PDF 解析器
description: 配置 AI 智能体读取科研论文的本地解析器或自托管 Open MinerU 服务
---

PDF 解析器将论文转换为 Markdown，再将文档写入知识库。默认的 `local` 引擎在应用所在机器上使用 [firecrawl-anydoc](https://github.com/firecrawl/anydoc) 解析，无需部署解析服务或提供 API key。`open_mineru` 引擎调用自托管 MinerU 服务，并额外提取图片。

两个引擎都将解析结果写入临时目录，再由公共存储流程将原始 PDF、Markdown 和提取的图片上传到 S3，将内容写入知识库，并清理临时文件。智能体从 S3 读取 Markdown 全文。

```toml
[pdf_parser]
engine = "local"
batch_size = 5
```

| Key | 默认值 | 说明 |
| --- | --- | --- |
| `engine` | `local` | 文本型 PDF 使用 `local`；自托管解析服务使用 `open_mineru`。 |
| `batch_size` | `5` | 文档片段写入知识库时的批量大小。 |
| `open_mineru.api_url` | `http://localhost:8000` | Open MinerU API 根地址。 |
| `open_mineru.timeout` | `600` | 请求超时，单位为秒。 |

<Callout type="warn">
  `local` 不执行 OCR，也不提取独立图片文件。包含扫描页的 PDF 会解析失败，并提示配置 `open_mineru`；不会发送到 Firecrawl 云端 OCR 服务。配置类型仍接受 `mineru`、`doc2x` 和 `grobid`，但运行时调度器尚未实现这三个引擎。
</Callout>
