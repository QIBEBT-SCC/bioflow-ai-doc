---
title: PDF Parser
description: Configure the PDF parsing engine used by AI agents to read scientific papers
---

The PDF parser is used by AI agents to extract content from scientific literature when designing workflows from papers. Configure the engine in `config.toml`:

```toml
[pdf_parser]
engine     = "open_mineru"
batch_size = 5
```

| Key | Description |
| --- | --- |
| `engine` | Parsing backend to use. See options below. |
| `batch_size` | Number of PDFs to process concurrently. |

---

## Choosing an engine

| Scenario | Recommended engine |
| --- | --- |
| Have a GPU server, want best quality | `open_mineru` |
| No GPU, don't want to self-host | `mineru` or `doc2x` |
| Don't need PDF analysis at all | `local` |
| Need structured reference extraction | `grobid` |
