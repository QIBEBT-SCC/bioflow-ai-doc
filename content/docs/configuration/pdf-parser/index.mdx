---
title: PDF Parser
description: Configure local PDF parsing or a self-hosted Open MinerU service for AI agents
---

The PDF parser converts papers to Markdown before writing them to the knowledge base. The default `local` engine uses [firecrawl-anydoc](https://github.com/firecrawl/anydoc) on the application host and requires no parser service or API key. The `open_mineru` engine calls a self-hosted MinerU service and also extracts images.

Both engines write parsing artifacts to a temporary directory. The shared storage flow uploads the original PDF, Markdown, and any extracted images to S3, writes the content to the knowledge base, and cleans up the temporary files. Agents read the Markdown from S3.

```toml
[pdf_parser]
engine = "local"
batch_size = 5
```

| Key | Default | Description |
| --- | --- | --- |
| `engine` | `local` | Use `local` for text-based PDFs or `open_mineru` for a self-hosted parser. |
| `batch_size` | `5` | Batch size when inserting document chunks into the knowledge base. |
| `open_mineru.api_url` | `http://localhost:8000` | Open MinerU API root. |
| `open_mineru.timeout` | `600` | Request timeout in seconds. |

<Callout type="warn">
  `local` does not perform OCR or extract standalone image files. A PDF containing scanned pages fails with a message suggesting `open_mineru`; it is never sent to Firecrawl's hosted OCR service. The configuration still accepts `mineru`, `doc2x`, and `grobid`, but those engines are not implemented by the runtime dispatcher.
</Callout>
