---
title: 知识库
description: 配置 Milvus 和 OpenAI-compatible 嵌入模型 API
---

知识库将工具文档和参数说明写入 Milvus，为 AI 智能体的工具发现和工作流设计提供检索。当前配置结构是单一的 `[knowledge_base]` 段：

```toml
[knowledge_base]
milvus_url = "http://localhost:19530"
embedding_model = "Qwen/Qwen3-Embedding-4B"
base_url = "https://api.siliconflow.cn/v1/"
api_key = ""
```

| Key | 默认值 | 说明 |
| --- | --- | --- |
| `milvus_url` | `http://localhost:19530` | Milvus 地址；初始化端口发生冲突时会自动更新。 |
| `embedding_model` | `Qwen/Qwen3-Embedding-4B` | 发送给嵌入 API 的模型名称。 |
| `base_url` | SiliconFlow `/v1/` | OpenAI-compatible API 根地址。 |
| `api_key` | 空 | 嵌入服务凭据。 |

`auto-init` 会询问嵌入模型、base URL 和 API key。系统预置数据初始化需要嵌入 API 和 Milvus 同时可用，否则无法建立向量索引。

<Callout type="warn">
  旧版文档中的 `use_local_model`、`[knowledge_base.remote]` 和 `[knowledge_base.local]` 已不是有效配置。未知字段会被忽略。
</Callout>

自托管模型也通过同一套 OpenAI-compatible API 接入，无需本地模式开关。详见[嵌入模型](/docs/configuration/knowledge-base/embedding-model)。
