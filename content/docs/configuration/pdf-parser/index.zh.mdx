title: PDF 解析器
description: 配置 AI 智能体读取科研论文的 Open MinerU 服务
---

PDF 解析器用于提取论文的 Markdown 和图片，再将文档写入知识库。当前运行时已实现的引擎是 `open_mineru`：

```toml
[pdf_parser]
engine = "open_mineru"
batch_size = 5

[pdf_parser.open_mineru]
api_url = "http://localhost:8000"
timeout = 600
```

| Key | 默认值 | 说明 |
| --- | --- | --- |
| `engine` | `local` | 解析引擎名称；需要 PDF 解析时请设为 `open_mineru`。 |
| `batch_size` | `5` | PDF 解析批量配置。 |
| `open_mineru.api_url` | `http://localhost:8000` | Open MinerU API 根地址。 |
| `open_mineru.timeout` | `600` | 请求超时，单位为秒。 |

<Callout type="warn">
  配置类型中仍保留 `mineru`、`doc2x`、`grobid` 和 `local` 名称，但当前 PDF 解析调度器只实现了 `open_mineru`。选择其他值会在解析时报“不支持的解析引擎”。
</Callout>
